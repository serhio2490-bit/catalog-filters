# Каталог услуг с фильтрами

Готовый модуль для сайта: панель фильтров-кнопок сверху и сетка карточек услуг под
ней. Карточка открывает окно «Подробнее» с полным описанием. Сетка сама
перестраивается: 3 колонки на мониторе, 2 на планшете, 1 на телефоне.

Стек: React + Vite + Tailwind. Ни базы данных, ни сервера — обычная статика,
выкладывается на любой хостинг.

## Как добавить или изменить услугу

Все услуги описаны в одном файле — **`src/data/services.js`**. Программист для этого
не нужен: откройте файл, скопируйте любой блок и поменяйте текст.

```js
{
  id: "new-service",          // латиницей, без пробелов, уникальный
  category: "repair",         // repair | cleaning | appliances | removal
  title: "Название услуги",
  short: "Одна строка для карточки.",
  price: "от 2 000 ₽",
  duration: "1–2 часа",
  full: "Полное описание — его видно в окне «Подробнее».",
  includes: ["Первый пункт", "Второй пункт", "Третий пункт"],
},
```

Категории задаются в том же файле, в списке `categories` выше. Счётчик у каждой
кнопки фильтра считается сам — руками его править не нужно.

## Запуск

```bash
npm install
npm run dev
```

Страница откроется на `http://127.0.0.1:4321`.

Сборка для выкладки:

```bash
npm run build
```

Готовые файлы появятся в папке `dist` — её и кладут на хостинг.

## Что внутри

- `src/data/services.js` — все услуги и категории (единственный файл с текстами).
- `src/components/FilterBar.jsx` — панель фильтров.
- `src/components/ServiceCard.jsx` — карточка услуги.
- `src/components/ServiceModal.jsx` — окно «Подробнее».
- `src/components/Icon.jsx` — иконки, нарисованные кодом (SVG), без сторонних наборов.
- `src/index.css` — цвета, шрифт, размеры текста, радиусы и тени одним набором.

## Мелочи, которые обычно забывают

- Выбранная категория попадает в адрес страницы (`?category=repair`) — ссылкой можно
  поделиться сразу на нужный раздел, и кнопка «назад» в браузере работает.
- Фильтры и карточки доступны с клавиатуры, рамка фокуса видна.
- Окно «Подробнее» закрывается по Esc и по клику вне, фокус возвращается на ту же
  кнопку, фон под окном не прокручивается.
- Проверено на ширине 360, 768 и 1280 пикселей: горизонтальной прокрутки нет.
- Анимации отключаются, если в системе включено «уменьшить движение».

## Чего в модуле нет

Формы заявки, корзины, оплаты, админки, поиска по названию и тёмной темы. Это
отдельные задачи — модуль намеренно делает одно и делает целиком.
